# 使用范围与质量声明

系统定位是内部资料检索与工程排查辅助。可以在无专家标签的情况下使用、运行软件回归并通过反馈修正问题；不把工程复核设为开始使用的前置审批。

引用校验说明回答可追溯到返回的来源，不说明来源结论正确。OCR 数字、讨论中的参数、候选原因和材料适用范围需要对应依据，软件测试通过不能自动将其升级为已核验工艺结论。

`pcb_assistant/evaluation/release.py` 使用正式发布口径检查独立评测、适用的客户端或托管能力等条件。其 `release_ready=false` 与内部工具可用是不同范围；不得为了消除阻断而伪造标签、复核记录或性能指标。

需要对外工程质量承诺或启用新的外部能力时，再执行对应的验证任务。日常发现引用错配、检索偏移或上下文缺口，通过[反馈台账](INTERNAL_PILOT_FEEDBACK.md)记录。可选复核和开发工具见[开发说明](DEVELOPMENT.md)。
